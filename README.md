# Lunerya marketing media

Public, media-only repository (GitHub Pages) used to host **finished, publicly distributable** Lunerya marketing images and
videos, so that official publishing tools (Buffer, Pinterest) can fetch them by URL.

Allowed: finished marketing images (.png, .jpg) and videos (.mp4) and their cover images, inside dated week folders.
Never: application source code, credentials or keys, internal reports, unpublished release information, user data, or
contents of any private repository. A repository hook enforces the file-type rule.
